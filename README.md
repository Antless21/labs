Средняя сложность №2
Сумма всех нечётных чисел от 1 до N включительно. Цикл for с шагом 2 перебирает только нечётные числа.

python
def sum_numbers(num):
    """Возвращает сумму всех нечётных чисел от 1 до num включительно."""
    total = 0
    for i in range(1, num + 1, 2):
        total += i
    return total
Пример:

python
print(sum_numbers(10))  # 25
Проверка: 1 + 3 + 5 + 7 + 9 = 25.

Средняя сложность №4
НОД двух натуральных чисел методом перебора: делители проверяются от меньшего из чисел вниз до 1, первый общий делитель и есть НОД.

python
def gcd_simple(a, b):
    """Возвращает НОД двух натуральных чисел перебором делителей."""
    if a <= 0 or b <= 0:
        raise ValueError("Числа должны быть натуральными")
    for d in range(min(a, b), 0, -1):
        if a % d == 0 and b % d == 0:
            return d
Примеры:

python
print(gcd_simple(48, 18))  # 6
print(gcd_simple(17, 5))   # 1
Средняя сложность №7
Подсчёт гласных букв (русских и английских) в строке. Регистр не учитывается, так как строка приводится к нижнему регистру.

python
def count_vowels(text):
    """Возвращает количество гласных букв (русских и английских) в строке."""
    vowels = "аеёиоуыэюяaeiou"
    count = 0
    for char in text.lower():
        if char in vowels:
            count += 1
    return count
Примеры:

python
print(count_vowels("Привет, мир!"))  # 3
print(count_vowels("Hello World"))   # 3
Повышенная сложность №2
Алгоритм Евклида: НОД(a, b) = НОД(b, a % b), пока остаток не станет равным нулю. Работает значительно быстрее перебора.

python
def gcd_euclid(a, b):
    """Возвращает НОД двух натуральных чисел по алгоритму Евклида."""
    if a <= 0 or b <= 0:
        raise ValueError("Числа должны быть натуральными")
    while b != 0:
        a, b = b, a % b
    return a
Пример работы для чисел 48 и 18:

(48, 18) -> (18, 12) -> (12, 6) -> (6, 0)   НОД = 6
Сравнение двух способов:

python
print(gcd_euclid(48, 18))                              # 6
print(gcd_euclid(17, 5))                               # 1
print(gcd_simple(1071, 462) == gcd_euclid(1071, 462))  # True
